# Hayame 2.0 - Updates (2026-02-04)

## Messaging
- Added in-app messaging UI with realtime updates and unread badge in header.
- Created `/messages` page with conversation list and chat thread UI.
- Added conversation creation endpoint and host message presets from listing page.
- Added messaging state provider and realtime subscription handling.

## Host Messaging & Profiles
- Added "Message host" panel on car listing pages with preset messages.
- Added host profile page at `/hosts/[id]` showing host details and all listings.
- Wired "View host" link to new host profile page.

## Admin Enhancements
- Added admin edit access for any listing (edit & availability).
- Added admin filters manager UI to add/edit/delete car makes and models.
- Added admin filters API routes for makes/models.

## Search & Filters
- Added brand, model, and fuel type filters across search and explore pages.
- Added fuel type enum support and updated forms/validators.
- Added car catalog hook to load makes/models from database.
- Updated explore filtering to include brand/model/fuel and search by these fields.

## Car Details
- Listing details now show brand, model, and fuel type.
- Updated car forms to select brand/model/fuel from catalog.

## Signup & Profiles
- Signup now uses region + city dropdowns from DB locations.
- Added secure server route for profile upsert to fix RLS errors.

## UI / Layout Fixes
- Fixed dashboard mobile layout for host and user.
- Fixed explore card stretching and removed extra space above listings when filters are active.
- Updated hero fade to black.

## Schema / SQL (Applied or Provided)
- Added fuel type enum and columns for brand/model/fuel_type on cars.
- Added car makes/models catalog tables and seed SQL.

## Technical Notes
- Updated Tailwind brand tokens to use CSS variables.
- Added car catalog fetch API and client hook.
- Messaging realtime de-duplication fix.
