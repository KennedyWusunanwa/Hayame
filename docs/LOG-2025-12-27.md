# Daily Log - 2025-12-27

## Summary
- Improved mobile navigation and accessibility, refined hero/search UX on mobile, and tightened Explore responsiveness. Added Supabase auth/profile safeguards, real car editing with photos, and resolved build/type issues. All changes are on `main` at `https://github.com/KennedyWusunanwa/Hayame.git`.

## Changes
- **Navbar / Mobile sheet**
  - Visible white sheet with dark text, accessible description, and full header actions (Log in/Sign up when signed out; user badge, Dashboard, List your car, Sign out when signed in).
  - Explicit open/close handling and transitions so the panel appears above the overlay.
- **Hero search (homepage)**
  - Date input now shows a “Dates” placeholder on mobile; switches to native date picker on focus so the placeholder remains readable when unfocused.
  - Hero CTA points to listings; contrast fixes with stronger overlay and explicit text colors.
- **Explore page responsiveness**
  - Adjusted padding and grid to avoid clipping on small screens.
  - Map panel constrained height with overflow handling on mobile; card grid now 1/2/3 cols for mobile/tablet/desktop.
  - Markers cleaned up to `city • name` with `₵` price formatting.
- **Auth / Supabase**
  - Supabase server client now awaits cookies/headers to fix `cookieStore.get is not a function`.
  - Defensive profile upsert before car create/update to satisfy `cars.owner_id` FK; simplified upsert to avoid `.catch` runtime errors.
  - Provided SQL backfill snippet to create profiles for any missing auth users.
- **Dashboard Cars**
  - Edit page loads the real car from Supabase, then checks ownership; form defaults to live data (not mock).
  - Fixed type errors by casting to the cars row type; PhotoUploader and AvailabilityForm use the typed car id.
  - Dashboard link added to navbar when signed in; “List your car” and “Sign out” gated by auth.
- **Media / Storage**
  - PhotoUploader writes to the `car-photos` bucket, stores URLs in `car_photos`, and loads existing photos for a car.
- **UI / Buttons / Logo**
  - Brand buttons invert on hover (blue → white/blue outline; outline → blue/white).
  - Navbar logo resized for better fit; mobile menu icon enlarged; hero/search inputs made readable on dark surfaces.
- **Dependencies / Build**
  - Removed `react-day-picker` (React 18 peer mismatch) and addressed dashboard edit type errors; `npm run build` now passes locally.

## Configuration / Environments
- **Repository:** `main` branch on `https://github.com/KennedyWusunanwa/Hayame.git` (pushed via HTTPS).
- **Local dev:** `npm run dev` (Next.js 16, React 19). Use `.env.local` with Supabase URL/anon key as in `.env.example`.
- **Vercel:** Builds from `main`; ensure `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` (and storage bucket vars) are set.
- **Database:** Supabase schema/RLS in `db/migration.sql` and `docs/RLS.md`; bucket `car-photos` required for uploads.
